## How I work

I start with the task and its failure cases, design the workflow, and use AI coding tools to build and iterate. I care about source traceability, readable checkpoints, bounded costs and evidence that a system did what it claimed.

My work uses Python, TypeScript and JavaScript, Bash, Swift and SwiftUI, Markdown and Git. Much of the tooling runs locally on macOS.

I also build with [Will Leikauskas](https://github.com/leikauskas) through [Camillo Labs](https://github.com/camillo-labs), including tools for personal AI systems and video production.
